# Eneffplan

Custom CRM/ERP für ein Energieeffizienz-Planungsbüro — löst Crewmeister, Microsoft Planner, Excel (Controlling/Projektübersicht) und Lexware durch ein einziges System ab.

## Struktur

- [`docs/requirements.md`](docs/requirements.md) — Lastenheft, destilliert aus dem Kickoff-Gespräch mit dem Kunden. Enthält Ist-Zustand, Anforderungen, Priorisierung und offene Punkte.
- [`app/`](app) — Klickbares Mockup (Look & Feel) als React/Vite/Tailwind-App mit Beispieldaten. Kein echtes Backend, keine echte Datenpersistenz — reine Oberflächen-Demo für die Angebotsphase.

## Aktuelle Phase

Angebotsphase: Mockup + Aufwandsschätzung + laufende Kosten + ROI-Rechnung für den Kundentermin am 27.10.2026. Noch **kein** Bau des echten Systems (siehe [docs/requirements.md](docs/requirements.md), Abschnitt 6.1).

## Mockup lokal starten

```bash
cd app
npm install
npm run dev
```
